- Implementation: `ZoneSnapshot.diff` reports immutable added/changed/removed ID sets. A tenant-scoped atomic registry rejects non-monotonic versions. PostgreSQL migration V2 stores zone sets, immutable zone versions, tombstones, hashes, and optional idempotency keys. `JdbcSnapshotLoader` validates set status and composes published history; only candidate loads may include their exact BUILDING set. `JdbcZoneSetStore` uses independent short transactions for allocation/edit, publication, and failure. `ZoneSetPublisher` validates before allocation, holds a per-tenant lane across candidate build/commit/swap, uses a bounded builder pool, and fails the service closed after a post-commit local-swap failure. `PinnedSnapshotRegistry` reference-counts active snapshots and uses Caffeine weighted by vertex count for unpinned history.
